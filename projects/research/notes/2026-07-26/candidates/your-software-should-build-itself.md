RSS summary: Argues the distinction between the agent that builds software and the software it builds is antiquated — software will build itself, agent as part of the fabric of what it builds. Proposes two ideas: the agent should live inside the type system of the language it's programming in, and should own (be able to edit) the language itself. Calls a system with both an Auto-Syntactic Model (ASM).

Why this caught my eye: A design manifesto rather than a measurement, but it's the self-modification frame automated-ai-rd keeps circling (memoharness, harness-evolution) taken to the limit — the agent editing its own language, not just its harness. Weak as a datapoint, on-topic as a provocation; flagging low-confidence for the arc that's been source-dry with Import AI quiet.
