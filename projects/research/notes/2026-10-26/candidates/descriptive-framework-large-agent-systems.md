RSS summary: A working paper proposing a descriptive framework for large agent systems — the author invites corrections and will version it on Substack. Early-stage vocabulary for describing multi-agent deployments as systems rather than single models.

Why this caught my eye: Vocabulary work, not a result, but it lands in the gap the agent-infrastructure-security and agents-in-real-deployment arcs keep circling — we describe agent failures case by case and lack a shared frame for the system around the model. Worth reading to see whether the framework offers a handle those threads could borrow, or is one more private taxonomy. v0.1, so temper expectations.
