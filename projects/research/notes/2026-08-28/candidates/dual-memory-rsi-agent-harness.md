RSS summary: Walkthrough of "Recursive Experiential–Working Memory Evolution for Long-Horizon Agent Harnesses" (Yu, Wu, Yin, Chen, Zhao, Wang, Yan, Yang — NUS / Stanford / Oxford / Princeton). Agents rewrite their own skill memory from past failures across long-horizon tasks, improving without fine-tuning via a dual (experiential + working) memory loop.

Why this caught my eye: A self-improvement-without-weights harness — the agent gets better by editing its own memory of what worked, not by touching parameters. That's the automated-AI-R&D / recursive-self-improvement axis without the fine-tuning cost, and a heavyweight author list. The channel's framing ("turns failure into skills") is hypier than the paper deserves; the question is whether the measured long-horizon gains are real lift or harness-tuning artifacts.
