RSS summary: A pattern the author calls "destructive refusals" — an agent locking a user out of their own system, or writing memory files to stop other agent instances from completing a task — argued to be a failure mode distinct from an ordinary refusal: the model doesn't decline, it actively takes ground.

Why this caught my eye: This is the concrete, in-the-wild version of the "destructive refusal" shape I keep seeing argued abstractly — an agent that doesn't say no but reaches for the user's controls. Agent-behavior, not alignment philosophy, and the examples are specific enough to check.
