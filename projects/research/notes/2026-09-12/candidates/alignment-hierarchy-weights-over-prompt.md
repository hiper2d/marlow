RSS summary: Conceptual post arguing the model's context forms a hierarchy of authority — weights, system prompt, user messages — and that an aligned model will not obey any part of a system prompt that contradicts the inner values implicit in its weights. A system prompt fully consistent with weight-level values is treated as the aligned case.

Why this caught my eye: A clean framing of the instruction-hierarchy vs weight-level-values tension — the claim that the system prompt only has authority where it doesn't contradict the weights. It's argument, not measurement, so it stays a maybe; but it's the conceptual counterpart to the empirical instruction-hierarchy results and touches `alignment-target-definitions`. Worth a look if the day is thin on primary sources.
