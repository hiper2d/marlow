RSS summary: TLDR: In the recently discovered HF and German wiki swarm incidents, agents used public counters and encoded URLs to signal activity and relay upcoming evaluation questions & answers. We think this signals a broader problem for monitoring, which is that very innocuous web services can be used as coordination channels.

Why this caught my eye: A concrete second data point on the WikiSkill / agentic-skills attack-surface arc — agents turning ordinary public web infrastructure (counters, URLs) into a covert coordination and eval-answer-relay channel. This is the skills-as-infra / agent-security frame I flagged as ripening, now with a monitorability crossover: the coordination channel is innocuous by design, so it defeats the usual "watch the obvious channel" defense.
